# Sentinel TO

A live public safety map of Toronto built from official public data. It layers traffic cameras, 511 incidents and vehicle counts on one map.

**Wait or Reroute:** each crash card shows whether the road is getting worse, holding steady, clearing or unknown, with the camera evidence and a confidence level. If cameras are frozen or offline, the status is unknown, never all clear.

**Status:** in progress.

It uses official public feeds only and counts vehicles without identifying or tracking anyone. It's a public awareness tool, not an emergency service, and shouldn't be used while driving.
